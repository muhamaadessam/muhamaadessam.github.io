Questions and answers in glass cards. Uses definition-list markup so screen readers announce each pair.

## When to use

- Short questions about hiring, availability or the work process.

## Consumer provides

- `items`: `[{ question, answer }]`.

## Specs

- Single column, maximum width 768px. Gap `space-4`.
- Question 18px semibold in `white`. Answer 16px in `gray-300`.
