Translucent glass panel for content that floats over the textured hero or project grid.

## When to use

- Project tiles, skill groups and contact blocks on the dark page.
- Use `surface-card` (solid) instead when the panel sits on a busy background or must stay readable in light mode.

## Consumer provides

- The heading (`heading-3`) and body copy (`body-sm`, `gray-300`).
- Optional footer actions, separated by a `border-subtle` rule.

## Specs

- Fill `glass-fill`, 1px border `glass-edge`, backdrop blur 16px.
- Padding `space-6`; gap `space-4` between blocks.
- Radius `radius-2xl`.
