Project grid. Each item renders as a ProjectCard, in one, two or three columns depending on width.

## When to use

- The projects section of a portfolio.

## Consumer provides

- `items`: the ProjectCard fields (`title`, `description`, `tags`, `image`, `imageAlt`, `links`).

## Specs

- One column below 768px, two from 768px, three from 1024px. Gap `space-8`. Maximum width 1152px.
